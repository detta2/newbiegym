# NOTICE — Asset Credits & Licenses

## Exercise animations (WebP)

The movement animations in `assets/exercises/*.webp` were converted (resized to
180px, re-encoded to animated WebP) from GIF files in the
**hasaneyldrm/exercises-dataset** (https://github.com/hasaneyldrm/exercises-dataset),
which is distributed under a Creative Commons license. The dataset's exercise
selection and naming were cross-referenced via the OpenGym project
(https://github.com/alexpcosta/opengym), which uses the same upstream dataset.

## In-house diagrams (SVG)

The diagrams for **Pike Push-up, Face Pull, Air Squat, Dead Hang,** and
**Wall Sit** (`assets/exercises/*.svg`) have no counterpart in the dataset and
were drawn by the NewbieGym project itself.

## App code

NewbieGym's code is an original work inspired by the concept of OpenGym
(alexpcosta/opengym); no OpenGym code is included.
